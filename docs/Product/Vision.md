# Vision for Xenon Project
This project is a successor of Krypton, which was positioned as an "Agentic Obsidian". We'll do better this time.

Main Objective: Not to build something Novel. Just start building.


---
### The Plan
The Plan with this project is to build a complete Knowledge Management System. On a very high level, manage your knowledge as notes, ingest anything and query on your own vault of knowledge.

Think of Obsidian with a Complete RAG System built on top of your vault.


> Over time, the application should become a unified knowledge platform capable of indexing documents, web pages, PDFs, code snippets, research papers, and conversations. Rather than simply storing information, it should help users discover insights, identify relationships, and build a long-term external memory.
