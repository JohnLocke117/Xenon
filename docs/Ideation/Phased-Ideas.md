## Phase 1 — Capture
This is the MVP.

Knowledge comes from:

Rich text notes
Markdown
PDFs
Images
Links
Code snippets

Later:

Browser extension
Mobile app
Voice notes
Email forwarding
GitHub repositories
RSS feeds


## Phase 2 — Organisation
This is where most note apps stop.
We can go much further.

Knowledge can be organised by:

Tags
Folders
Collections
Projects
Topics
Books
Courses

Eventually even:

Operating Systems
    |
    |---- Scheduling
    |
    |---- Memory
    |
    |---- File Systems


## Phase 3 — Relationships
This is where it becomes a knowledge platform.

Instead of isolated notes:

```
OS Note
↓
Links to
↓
Process Scheduling
↓
Links to
↓
Linux CFS
↓
Links to
↓
OSTEP Chapter 7
```

Now knowledge becomes a graph.


## Phase 4 — Search
Initially:

PostgreSQL Full Text Search

Later:

Semantic Search
Hybrid Search
Filters
Saved Searches
Search Ranking
Phase 5 — Enrichment

Imagine uploading a PDF.

The system could:

Extract text
OCR images
Generate embeddings
Identify entities
Recommend tags
Find related notes
Suggest missing concepts

Now we're enriching knowledge.



## Phase 6 — Retrieval
This is where AI becomes genuinely useful.

Instead of:

"Find my networking notes"

We ask:

"What were the differences between TCP Reno and Cubic?"

The system searches everything you've ever stored.


## Phase 7 — Learning
This is something most PKM tools don't do well.

Imagine reading DDIA.

The platform notices:

We haven't reviewed replication recently.
We have 12 notes mentioning Raft.
We never connected Raft with Paxos.

It suggests:

Review cards
Related notes
Quiz questions
Reading paths

Now it's actively helping us learn.
